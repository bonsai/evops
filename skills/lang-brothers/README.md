# ラング三兄弟 × SF 落語 4コマ漫画企画

## 企画者（エージェント構成）

### ラング三兄弟（ラングサンキョウダイ）

```
長男（ラング兄）：論文を読む、評価軸を整理する（論理担当）
次男（ラング次）：実験をする、データを見る（観察担当）
三男（ラング三）：発想を飛ばす、SF 落語に変換（発想担当）
```

### 配役案（4コマ漫画のキャラクターとして使う）

**案A：弥次喜多（やじきた）** — 旅人の掛け合いで論文を解説
- 弥次（やじ）：長男（論理、評価軸）
- 喜多（きた）：三男（発想、SF 変換）
- 旅先の宿屋（ご隠居）：次男（実験データ）

**案B：はっちゃん、熊さん、ご隠居さん** — 落語の三役で論文を解説
- はっちゃん（八っつぁん）：長男（論文を読む）
- 熊さん（熊さん）：次男（評価をする、データを見る）
- ご隠居さん（ごいんきょ）：三男（知恵を授ける、落語のオチをつける）

→ 今回は **案B（はっちゃん・熊さん・ご隠居さん）** を採用。

---

## 4コマ漫画の構造（SF 落語の型）

```
コマ1（問題提起）    はっちゃんが論文を持って困っている
                    熊さんが「これは評価の話だよ」と言う

コマ2（異常/手法）  ご隠居さんが「細粒度評価を自動化するんだ」と教える
                    熊さんが評価軸を見せる（CLIP、色彩、構造）

コマ3（発明/突破）  はっちゃんが「評価ループが知識になるんだ！」と気づく
                    ご隠居さんが光を放つ（発見の瞬間）

コマ4（つながり）    三人が一緒に「生成→評価→修正→再生成」のループを描く
                    最後に「知識とはループである」という落語のオチ
```

---

## エージェントの役割分担（疎結合）

```
[Paper Survey Agent] → 抽出（abstract, keywords, relevance）
        |
        v
[Lang Brothers Agent] → 4コマ企画（キャラ割当、セリフ、オチ）
        |
        v
[SVG Generator (svg-gen.py)] → 描画（吹き出し、棒人間、テロップ）
        |
        v
[Kamishibai CLI] → アニメーション化（MP4）
        |
        v
[Telop CLI] → 字幕/クレジット焼き込み
        |
        v
[Video Editor (videogen)] → 最終 MP4 出力
```

各工程は JSON 契約（`episode.json` / `char_tkt_contract.md`）でのみ接続。

## 企画の作り方（CLI で実行）

### 1. 論文サーベイから抽出

```bash
# evops/mcp/sf-paper-comic の CLI を使って抽出
python -c "
import sys, json, os
sys.path.insert(0, '.')
# サンプルとして P03 を読み取り
paper_dir = 'mcp/papers/P03-videoscore-2024'
with open(f'{paper_dir}/README.md') as f: content = f.read()
# 簡易抽出（実際には NLP でアブストラクト解析）
print(json.dumps({
    'id': 'P03-videoscore-2024',
    'title': 'VideoScore: Building Automatic Metrics',
    'hook': '細粒度評価を自動評価へ変換',
    'keywords': ['evaluation', 'feedback'],
    'relevance': 'VLM 評価を生成改善のフィードバックへ接続'
}))
"
```

### 2. ラング三兄弟による企画生成

```bash
# 新しいスキルを作成
mkdir -p /home/bons/evops/skills/lang-brothers

# 企画生成スクリプト（CLI スキル）
# scripts/lang_brothers_plan.py から episode.json を出力
node skills/lang-brothers/scripts/plan.js \
  --input P03-videoscore-2024.json \
  --format SF-4koma \
  --characters hatchan,kuma,goin_kyo \
  --output episode.json
```

### 3. SVG 描画（svg-gen.py で吹き出しとテロップ作成）

```bash
# svg-gen.py を使って 4 コマ SVG を生成
python skills/svg-gen/scripts/svg-gen.py \
  --font IPAexGothic \
  --bubbles "問題提起,異常/手法,発明/突破,つながり" \
  --output sf_comic_4koma.svg
```

### 4. アニメーション化（kamishibai CLI で MP4 化）

```bash
# kamishibai の CLI で SVG → MP4
node /home/bons/kamishibai/cli/render.js episode.json /tmp/episode.mp4
```

## 疎結合の原則（ラング三兄弟版）

```
[論文 DB] → [Paper Survey Agent] → [episode.json]
      ↓
[Lang Brothers Agent] → 企画（キャラ割当、セリフ、オチ）
      ↓
[SVG Generator] → 描画
      ↓
[Kamishibai] → アニメーション（MP4）
      ↓
[Telop] → 字幕/クレジット焼き込み
      ↓
[Videogen] → 最終 MP4 出力
```

各工程は `episode.json` のみを契約とし、直接依存なし。ラング三兄弟の企画は `episode.json` の `characters` フィールドにキャラクター情報を入れるだけで、描画・動画化には影響を与えない（独立して交換可能）。
