# ロードマップ

## Phase 0: 環境整備（1-2 日）

- [ ] Blender + bpy 動作確認
- [ ] Python 仮想環境整備
- [ ] SQLite / ChromaDB インストール
- [ ] Plotly / PyVista 動作確認
- [ ] Kaggle アカウント作成

## Phase 1: 最小画像生成パイプライン（1 週間）

- [ ] SVG 生成（手書き + コード生成）
- [ ] Blender bpy で SVG インポート・レンダリング
- [ ] パラメータ → SVG → 画像の自動化
- [ ] 生成物を `generated_items/` に保存

## Phase 2: 最小評価ループ（1 週間）

- [ ] 評価 DB スキーマ設計
- [ ] 人間評価用 TUI or CLI 作成
- [ ] 1 プロンプト → 生成 → 評価 → 再生成のループ
- [ ] 履歴を DB に永続化

## Phase 2.5: インテント推定型評価エージェント（1 週間）

- [ ] LangChain / LangGraph / LangSmith 環境構築
- [ ] Intent Estimator（人間スコアから価値関数を推定）
- [ ] Criteria Generator（推定インテント → 評価基準）
- [ ] Meta-Optimizer（人間スコアとの相関最大化）
- [ ] ペアワイズ比較によるインテント学習

## Phase 3: 統計・可視化（1 週間）

- [ ] 評侒スコアの時系列プロット
- [ ] パラメータ vs スコアの相関分析
- [ ] PyVista でパラメータ空間 3D 可視化
- [ ] ダッシュボード原型

## Phase 4: 機械学習導入（2 週間）

- [ ] 画像特徴量抽出（CLIP / DINOv2）
- [ ] 人間評価予測モデル作成
- [ ] Kaggle コンペ 1 つ参加 or 完走
- [ ] 予測結果を評価ループに組み込む

## Phase 5: 小説・文章評価（2 週間）

- [ ] 日本語文章の自動指標計算
- [ ] 感情分析・テーマ類似度実験
- [ ] 画像と文章を組み合わせた「絵本」試作
- [ ] ポートフォリオページ作成

## Phase 6: 統合・ポートフォリオ化（1-2 週間）

- [ ] 全データの可視化ダッシュボード
- [ ] ポートフォリオ Web サイト（presen/ などに展開）
- [ ] カイカイキキ求人への応募資料整理
- [ ] README / デモ動画作成

## 進め方の心構え

- 完璧を目指さず、各 Phase で「動く最小単位」を作る
- 人間の設計・評価は常に入る位置に置く
- 機械に任せる部分は「人間が納得できる透明性」を保つ
- 統計データは人間の判断を支援するためのもの
