# 統計データの可視化

## 目的

- 生成・評価ループの全体像を直感的に把握する
- 人間の判断材料を増やす
- パターン発見（何が良い生成を生むか）

## 可視化対象

### 1. 時系列プロット

- プロンプト / 生成物ごとの評価スコアの推移
- 改善が続いているか、頭打ちかを視覚化

### 2. 分布プロット

- 全生成物のスコア分布
- 特定パラメータの値ごとのスコア比較

### 3. 散点図 / 相関

- 自動指標 vs 人間評価の相関
- パラメータ間の関係

### 4. クラスタリング可視化

- 生成物の特徴量を 2D/3D に射影
- 類似作品の群を発見

### 5. 3D 可視化（PyVista）

- パラメータ空間を 3D で探索
- 評価スコアを高さや色で表現
- 山（良い領域）と谷（悪い領域）を発見

## ツール

| ツール | 用途 |
|--------|------|
| **Plotly** | インタラクティブな 2D/3D グラフ、ダッシュボード |
| **PyVista** | 3D 可視化、点群、メッシュ、体積レンダリング |
| **Matplotlib / Seaborn** | 静的な分析グラフ |
| **Streamlit / Gradio** | 簡易 UI・ダッシュボード |

## ダッシュボード案

```text
┌─────────────────────────────────────┐
│  評侒スコア推移（折れ線）           │
├─────────────────────────────────────┤
│  スコア分布（ヒストグラム） │ 自動指標 vs 人間評価（散布図） │
├─────────────────────────────────────┤
│  パラメータ空間 3D マップ（PyVista） │
├─────────────────────────────────────┤
│  最新生成物サムネイル + 評価入力     │
└─────────────────────────────────────┘
```
