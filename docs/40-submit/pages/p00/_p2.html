検討項目 3 / 10

Java か、Python か？言語は手段。採用理由と不採用理由の両方を書く。

06
結論採用言語

Python 3.13 を採用する。

採用理由
  • 検討項目 5 のスケジュール（開発期間 10/14–10/26）に間に合う。
  • GUI・ファイル入出力・機械学習の周辺ライブラリが揃う。
  • オブジェクト指向（クラス・継承・カプセル化）は Java と同じ考え方で書ける。
Java を採用しなかった理由
  • GUI とファイル入出力の実装コストが高い。
  • 本件で必要とする機能に、Java の強み（静的型検査・並行処理）は必須ではない。
