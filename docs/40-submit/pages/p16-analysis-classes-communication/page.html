2. コミュニケーション図（UC1）

BoundaryControlEntity

番号は協調メッセージの論理順序。外部生成エンジン自体は境界外の依存先として扱う。

3. 統合チェック

  • 同じ概念を「画像／成果物」「履歴／実行記録」など複数名で呼ばず、用語を統一する。
  • Boundaryに業務ロジックや永続化処理を持たせず、Controlが手順を調整する。
  • 生成設定は実行時点のスナップショットを残し、画像と実行履歴を実行IDで追跡できるようにする。
  • 入力不備・生成失敗・保存失敗を別の結果として扱い、p17のシーケンス図で分岐を確認する。
