SSSS Research Plan (400字)

LMS/VLM → DB → ML → Repair → Regenerate

本プロジェクトは LMS/VLM を共通評価器として使い、評価結果を DB へ蓄積し、ML による改善ループを回すことを目的とする。10 ヵ日のロードマップに従し、まず論文リサーチと評価 Ontology を設計し、CLIP、PickScore、ImageReward、HPSv2 といった軽量画像評価モデルを実装する。CPU 16GB 制約下では CLIP-small 等を活用し、多軸評価による質の近似を実現する。人間の嗜好はペアワイズ比較で収集し、Bradley-Terry や DPO により効率的に学習させ、高価な人間フィードバックのコストを抑える。MCP（Model Context Protocol）でツール層を標準化し、A2A（Agent2Agent Protocol）でジェネレータ・評価者・意図推定エージェント間の連携を実現する。Phi-3 や Llama 3.2 などの SLM を利用し、ローカル CPU 16GB 環境でループ回転させる。最終的に生成品質の指標改善と今後の展開を分析し、プロジェクトを完結させる。
