# Intent

## Research Intent
生成物ではなく、生成方法が評価によって改善され続ける仕組みを作る。

## Core Question
VLM/LMSによる評価と実験履歴の蓄積を使えば、アニメーション生成方法そのものを世代的に改善し、目標表現へ近似させられるか。

## Hypothesis
1. 生成結果だけでなく生成方法・コード・評価・修正を保存すれば、次の生成方法を改善できる。
2. 自然言語評価と数値評価を組み合わせることで、曖昧な「似ている」を測定可能なFitnessへ変換できる。
3. Elite / Mutation / Crossover / Repair / Killを使うことで、生成方法を探索できる。
4. 世代履歴を可視化すれば、「似ていない状態から近づく過程」自体を研究成果として示せる。

## Research Target
ドラえもんらしさを自然言語、コード、ピクセル、mm、角度、比率、構造、色・材質、カメラの複数表現で定義する。

## Success Image
最初の候補から世代を重ねるにつれてFitnessが上昇し、視覚的にも目標へ近づく。
