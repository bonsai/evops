# **コンピュータの発展に寄与した人々** 

**（独断と偏見が入っていることをご容赦ください）** 

**2026．8.27 西尾公伸** 

**（１）ジョージ・ブール（George Boole） 1815.11.2～1864.12.8 英国の数学者・論理学者。論理を代数的に扱う「ブール代数」の基礎を築く。 1854 年に「The Laws of Thought（思考の法則）」を著す。** 

**➡ のちにデジタル論理回路の理論的基礎となる。** 

**(2)クロード・シャノン（Claude Shannon）１９１６．４．３０～2001.2.24 ブール代数をリレー回路に適用し、デジタル論理回路の理論的基礎を作る。** 

**（３）アラン・チューリング（Alan Mathison Turing） 1912.6.23～1954.6.7 ドイツ軍のエニグマ暗号解読用の英国版暗号解読機Bombe の基本設計を行う。 計算可能性を定式化するチューリング・マシンのアイデア提唱 チューリング賞の名前として残る。** 

**(4)エドガー・ダイクストラ（Edsger Wybe Dijkstra） 1930.5.11～2002.8.6 オランダ人の計算機科学者。** 

**構造化プログラミングの主要な提唱者。（** ” **Go To Statement Considered Harmful** ” **CACM） 「構造化プログラミング」の中で、「手続きの抽象化」を説く。** 

**最短経路を求める「ダイイクストラ法」の考案者。** 

**(5)チャールズ・アントニー・ホア（Charles Anthony Richard Hoare）1934.1.11～2026.3.5 英国の計算機科学者。 クイックソートの考案者。 プログラムの正当性を形式的に記述する「ホーア論理」を提唱。 「構造化プログラミング」の中で「データの抽象化」を説く。** 

**(6)オーレ・ヨハン・ダール（Ole-Johan Dahl） 1931.10.12～2002.6.29 1960 年代にオブジェクト指向プログラミングのアイデアを生みだし、Simula67 を開発。 クリステン・二ゴールとの共同開発。** 

**(7)ニクラウス・ヴィルト（Niklaus Wirth）1934.2.15～2024.1.1 Pascal、Modula-2 などを開発した。** 

**「Algorithm + Data Structure = Programs(アルゴリズム＋データ構造=プログラム」)を著す。 （Pascal でPL/0 のコンパイラを示す）** 

**（８）アラン・ケイ(Alan Curtis Kay) 1940.5.17～ 「パーソナルコンピュータ」の概念を提唱。ダイナブック構想。 Xerox PARC でSmalltalk の開発を主導。「オブジェクト指向」という言葉を生み出した。**
