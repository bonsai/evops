# Seed Domains — evops 視座でのコンテンツ企画

evops のパイプライン（survey → plan → SVG → animate → voicevox → telop → edit → upload）は、
「論文」だけでなく、アイドル・お笑いなど任意の知識領域に応用できる。
ここでは **seed domain**（原種領域）として 3 つのテーマを定義し、各領域のノートと動画企画を示す。

---

## 1. 論文 — SF 落語 4 コマ（已定義）

| 項目 | 内容 |
|------|------|
| Seed | 最新の機械学習論文 |
| Hook | 「評価ループが知識になる」 |
| Cast | はっちゃん・熊さん・ご隠居さん |
| Voice | ななちゃん（Voicevox speaker 2） |
| Output | 4コマ漫画解説動画 |

### 企画例: P03 VideoScore
- コマ1: はっちゃんが「評価はできるが知識にどう繋がる？」と困る
- コマ2: ご隠居さんが「細粒度評価を自動評価へ」と教える
- コマ3: はっちゃんが「評価ループの中から成長パターンが見えた！」と気づく
- コマ4: 三人で「生成→評価→修正→再生成」のループを描く

### 利用スキル
`survey`, `lang-brothers`, `svg-gen`, `kamishibai`, `voicevox`, `telop`, `videogen`

## 2. アイドル — 「推し語り」解説動画

| 項目 | 内容 |
|------|------|
| Seed | アイドルグループの歴史・楽曲・メンバー |
| Hook | 「推しが輝く構造を知る」 |
| Cast | はっちゃん（ファン代表）・熊さん（データ担当）・ご隠居さん（業界の先輩） |
| Voice | ななちゃん（親しみやすいナレーション） |
| Output | グループ年表 / 楽曲解説 / 個性マップ動画 |

### 企画例: アイドルグループ X の歴史
- コマ1: はっちゃん「なんでこの曲がバズったの？」
- コマ2: 熊さんが楽曲データ・SNS 指標を提示
- コマ3: ご隠居さん「メンバー間の化学反応が起きた瞬間だ」
- コマ4: 三人で「推しの軌道」タイムラインを描く

### 利用スキル
`survey`（setlist DB / Wikipedia）, `lang-brothers`, `fontgen`（手書き風フォントでファン感）, `voicevox`, `telop`, `videogen`

---

## 3. お笑い — 落語・漫才の「オチ構造」解説動画

| 項目 | 内容 |
|------|------|
| Seed | 古典落語・現代漫才のネタ |
| Hook | 「おもしろさには構造がある」 |
| Cast | 弥次（ツッコミ）・喜多（ボケ）・ご隠居（落語家/解説者） |
| Voice | ななちゃん + 効果音（将来的に複数話者対応） |
| Output | ネタのオチ/伏線/間を可視化した解説動画 |

### 企画例: 古典落語「時そば」の構造
- コマ1: 弥次「そば屋で時間を売った？」（疑問）
- コマ2: 喜多「お客さんが『時間を買う』フリをするんだよ」（ボケ解説）
- コマ3: ご隠居「実は『口車』と『信頼』の逆転がある」（オチの構造）
- コマ4: 三人で「 setup → 逆転 → オチ 」の三角形を描く

### 利用スキル
`survey`（落語台本 DB）, `lang-brothers`, `svg-gen`, `kamishibai`, `voicevox`, `telop`, `videogen`

## evops 視座 — 共通の抽象化

どの seed domain でも以下の流れを固定化できる。

```
seed domain
   │
   ├── 事実収集（survey）
   ├── 物語化（lang-brothers cast）
   ├── ビジュアル化（svg-gen / kamishibai）
   ├── 音声化（voicevox ななちゃん）
   ├── テロップ化（telop）
   ├── 編集（videogen）
   └── 配信（upload）
```

差分は「入力ソース」と「キャラクター（cast）」だけ。これにより、
- 論文
- アイドル
- お笑い
- 歴史
- 料理レシピ
- プログラミング解説

など、任意の知識領域を同じ evops パイプラインで動画化できる。

---

## 次のアクション

1. `seed_domains.md` に新しいドメインを追加する場合は、cast・hook・企画例の 3 つを追記。
2. 各ドメイン用の `episode.json` テンプレートを `evops/templates/` に追加予定。
3. `chaperone` で `seed_domain` をパラメータ化し、1 コマンドでドメイン別動画を生成。
