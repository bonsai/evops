Function 5 / 7

5. 動画合成 (Compose)

画像・音声・字幕を1本の動画へmux

スライドショー生成

• ffmpeg: 5秒/コマ × 4コマ = 20秒
• クロスフェード 1秒
• 5fps → 30fps アップコンバート

mux（多重化）

• h264 映像 + aac 音声
• ASS字幕焼込み（IPAexGothic 24pt）
• 音声パディング（20秒に無音補完）

# ffmpeg command chain
# 1. concat images → raw.mp4 (with fade)
# 2. concat audio  → narration.mp3
# 3. mux video + audio + subs.ass → final.mp4

videogen / port 8006

Function 6 / 7

6. 品質評価 (Evaluate)

動画を多角的評価 → 改善提案 → ループ

review_paper_anime()

視覚品質・内容網羅性・構造的一貫性・字幕音声同期をチェック

suggest_improvements()

評価結果から優先度付きアクションを生成（regenerate / adjust / skip）

eval_loop()

評価→提案→修正→再評価をmax_iterations回 or target_score達成まで

Wide Gate

合格50 / A=80
字幕50% / 輝度0.15〜0.95
「ゆるくてOK」

Narrow Gate

合格75 / A=95
字幕90% / 輝度0.35〜0.75
「高品質のみ」

evaluator / port 8002 / gate_mode="wide" or "narrow"

なぜ7機能に分離したか

疎結合 (Loose Coupling)

各機能はJSON spec + CLI呼び出しのみで連携。直接importしない。Python/Node/Blender 言語の壁を越える。

独立進化可能

VisualizerをSDXLに差し替えても、DigestやAudioは変更なし。Adapter 1つ書くだけ。

段階的品質制御

Wide Gate で全機能を「ゆるく」回して動作確認 → Narrow Gate で個別に品質絞り込み。

チーム開発対応

7機能 = 7つの担当領域。MCP標準化により、外部Contributerもスキルを追加可能。
