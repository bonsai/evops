# 機械学習と Kaggle

## 目的

- 評価指標の学習
- 生成物の傾向抽出
- 人間評価と自動指標のギャップを埋める

## やりたいこと

1. **人間評価予測モデル**
   - 入力: 画像特徴量 or 文章特徴量
   - 出力: 人間がつけそうなスコア
   - 目的: 人間の負担を減らし、高速な探索を可能にする

2. **成功パターン抽出**
   - クラスタリングで「良い生成物」の共通特徴を発見
   - 次元削減（PCA, t-SNE, UMAP）で可視化

3. **異常検知**
   - 崩壊画像や品質の低い出力を自動検出

4. **強化学習 or ベイズ最適化**
   - パラメータ空間を効率よく探索
   - 評価スコアを最大化する生成パラメータを発見

## Kaggle で学ぶ内容

| 分野 | 具体例 |
|------|--------|
| 画像分類 / 回帰 | 美的スコア予測コンペ |
| 自然言語処理 | 文章の感情・品質評価 |
| 異常検知 | 不良画像検出 |
| 推薦 | ユーザーの好みに合わせた生成物選択 |
| 時系列 | 生成履歴のトレンド分析 |

## 技術スタック

- Python: `scikit-learn`, `lightgbm`, `xgboost`, `pytorch`, `tensorflow`
- 特徴量: `CLIP`, `DINOv2`, `ViT`, `BERT`, `Sentence-BERT`
- 最適化: `optuna`, `scikit-optimize`
- Kaggle: カーネル、データセット、コンペ参加

## プロジェクト内での役割

```text
[画像 or 文章] → [特徴量化] → [ML モデル] → [評価スコア予測] → [人間確認 or 自動採用]
                        ↑
                [DB に蓄積された過去の評価データ]
```
