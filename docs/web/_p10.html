検討 4

JEV を検索・推論に組み込む自然文クエリで過去の bpy コード差分を検索。失敗記述→類似事例推薦→修正指示生成。

--
目的

蓄積した bpy コード差分（git diff）と VLM 評価・失敗記述を「自然文」で検索・関連付け、過去の修正事例を参考に repair instruction を自動生成。

検索対象の整備
  • git diff 本体（bpy コード変更行）
  • VLM 評価 JSON（評価軸・スコア・失敗記述）
  • repair instruction（前回の修正指示）
  • JSONL / SQLite / vector db は不要で JEV だけで index 化できるか
JEV の活用場面
  • 自然言語クエリ（例：「鈴を追加した事例」）→ 該当差分の優先検索
  • 失敗記述の類似履歴推薦（collaborative repair）
  • 修正指示の生成補助（類似事例の差分を参考にした repair instruction）
技術的課題
  • JEV はセマンティック grep 用（自然文→正規表現）。diff 検索に適した形か
  • 大規模な diff 群の検索速度
  • 定量的な検索精度評価方法
LangChain / LangGraph と連携
  • JEV をエージェントの「Tool」として登録
  • 検索結果を LangGraph のノードに流入させる
  • 代替：埋め込みベクトル検索（RAG）とのリソース対効果比較
検討イシュー：https://github.com/bonsai/ssss/issues/1 テーマ2.md の `エージェント連携（A2A）`, `diff reviewer` も併せて参照。
