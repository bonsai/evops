# 小説・文章の評価

## 目的

画像生成だけでなく、文章（物語・小説）についても「機械に教えた上で評価補助を任せる」実験をする。

## 人間が定義するもの

| 項目 | 内容 |
|------|------|
| 作品のテーマ | 何について書かれているか |
| 文体・トーン | ユーモア、シリアス、詩的、簡潔 etc. |
| 構造 | 起承転結、三幕構成、非線形 etc. |
| 対象読者 | 年齢層、ジャンル嗜好 |
| 禁止事項 | 差別表現、過度な暴力、著作権侵害 etc. |

## 機械が計算できる指標

| 指標 | 計算方法 | 用途 |
|------|---------|------|
| 文字数 / 単語数 | 単純カウント | 長さ管理 |
| 読みやすさ | Flesch-Kincaid, 日本語の場合は係り受けの深さ etc. | 対象読者適合 |
| 語彙多様性 | TTR, MTLD, Shannon entropy | 単調さチェック |
| 文の長さ分布 | 統計量（平均、分散、最大最小） | リズム分析 |
| 感情分析 | ポジティブ/ネガティブ比率 | トーン確認 |
| キャラクター一致性 | ベクトル化 → 行動パターンのクラスタリング | キャラ崩れ検出 |
| プロット構造 | 出来事の密度、盛り上がり検出 | 構成の客観化 |
| テーマ適合度 | ターゲットテーマとの埋め込み類似度 | 目的との一致 |

## 評価プロセス

```text
1. 原稿投入
2. 自動指標計算
3. 人間が要所を確認し、総合評価を入力
4. (原稿, 自動指標, 人間評価) を DB 保存
5. 傾向分析 → 改善提案
```

## 応用

- 自分の小説の客観的フィードバック
- 画像生成と組み合わせた「絵本」プロジェクト
- 大量投稿サイト（小説家になろう等）の傾向分析

## ツール候補

- Python: `nltk`, `spacy`, `janome`, `mecab`, `transformers`
- 感情分析: `bert-base-japanese-sentiment` など
- 埋め込み: `OpenAI text-embedding`, `HuggingFace sentence-transformers`
