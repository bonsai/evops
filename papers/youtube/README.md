# SF論文四コマ YouTube

P01–P25の論文を、SF風の四コマ漫画 → 短編アニメ → YouTubeへ変換する。

## Concept
論文を「要約」するのではなく、研究上の発見を4コマの物語にする。

① 問題・謎 → ② 異変・失敗 → ③ 発明・研究手法 → ④ オチ・研究への接続

最後に必ず「この論文を、私たちの研究ではこう使う。」でhw-sotsuseiの研究ループへ戻す。

## Visual language
- SF研究所
- 博士 / 研究員 / AI / 謎の装置
- 白黒ベース + 論文アニメと同じ紫
- 四コマをSVGで構成
- コマごとにカメラ・文字・キャラクターをアニメーション
- 45–90秒のYouTube短編
- 1論文 = 1エピソード

## Episode template
1. 問い — 未来の研究所で何が困っている？
2. 異変 — 普通の方法では何が起きる？
3. 発明 — 論文は何を変えた？
4. オチ — その知識を研究ループへ戻す

## Production loop
Paper → Research finding → 4-panel SF script → SVG storyboard → SVG animation → Voice / SFX → YouTube → 視聴反応 → 次の脚本・演出

## First episodes
- P23 VQualA — AIは、どちらの絵が良いか分かるのか？
- P24 UniAPO — プロンプトをAI自身に進化させる
- P25 B-CODER — 成功したプログラムをAIが覚える

## Rule
論文の事実とSF演出を分離する。
- 事実: 論文が実際に示したこと
- 演出: キャラクター、台詞、未来設定、オチ
- 研究接続: hw-sotsuseiでどう使うか
SF部分を膨らませても、論文の実験結果を創作しない。
